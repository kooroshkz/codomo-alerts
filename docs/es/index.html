Listo en un minuto

Docker

docker run -d --name codomo-alerts --restart unless-stopped \
  -e CODOMO_CITIES="Granada" \
  -e CODOMO_PRICE_MAX=450 \
  -e CODOMO_GENDER=female \
  -e CODOMO_NOTIFY="tgram://BOT_TOKEN/CHAT_ID" \
  -v codomo-data:/data -p 127.0.0.1:8080:8080 \
  ghcr.io/kooroshkz/codomo-alerts

El panel está en localhost:8080. Funciona también en una Raspberry Pi o un NAS.

Python

pipx install codomo-alerts
codomo-alerts init
codomo-alerts watch

init hace unas preguntas y envía un mensaje de prueba.

CODOMO_GENDER es opcional: con female o male se saltan las habitaciones que Codomo marca solo para el otro género. Para toda España usa CODOMO_COUNTRIES=es.

Qué recibes

Tu búsqueda

Países, ciudades, dormitorios, presupuesto, duración del contrato, amueblado, fecha de entrada y habitaciones solo para mujeres o solo para hombres.

Solo lo nuevo

Habitaciones nuevas, las que vuelven a quedar libres, las de lista corta que pasan a reserva directa y bajadas de precio. Nunca la misma dos veces.

Registrar interés

Viviendas en las que Codomo elige a alguien de una lista corta, con cuántas personas se han apuntado ya.

Edificios nuevos

Un mensaje cuando aparece la página de un edificio nuevo en codomo.eu.

Panel

Qué hay libre, qué se ha ido y en cuánto tiempo, y a qué horas suelen salir.

Respetuoso

Una comprobación cada pocos minutos, más a menudo en las horas en que se publica. Dice quién es y frena cuando se lo piden.

Preguntas

¿Hay una app de Codomo que avise de habitaciones nuevas?

Codomo usa el perfil de búsqueda de tu portal de inquilino para las viviendas con registro de interés. Para recibir un mensaje por cada nueva publicación, filtrada a tu gusto y en la app que ya usas, está esta herramienta gratuita y no oficial.

¿Reserva por mí?

No. Te avisa y tú reservas en codomo.eu. Reservar con herramientas automáticas va contra sus condiciones. Deja una pestaña abierta con la sesión iniciada y estarás a un clic.

¿Y las habitaciones solo para mujeres o solo para hombres?

Codomo marca así algunas habitaciones de Granada y Linz. El aviso lo indica, y con CODOMO_GENDER=female o male se saltan las que no son para ti.

¿Qué es Codomo?

Codomo, antes Holland2Stay, alquila habitaciones, estudios y pisos en los Países Bajos, Granada, Carcavelos (Lisboa) y Linz. Esta herramienta no es de Codomo.

¿Necesito un servidor?

No. Sirve cualquier ordenador que se quede encendido: un portátil enchufado, una Raspberry Pi, un NAS o un VPS pequeño.

¿En qué idioma llegan los avisos?

En inglés, igual que el panel.
